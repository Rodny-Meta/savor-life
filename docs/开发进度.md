## 5. 环境与工具坑（经验沉淀）

- **阿里云镜像**：`D:\Dev\SDK\Maven\conf\settings.xml` 的 `<mirrors>` 原本全被注释（`localRepository` 倒是指向了 `D:\Dev\Cache\Maven`），直连 central 被 DNS 拦截。已在该文件补上 `aliyunmaven` 镜像块（mirrorOf `*`）。**这是一次全局配置变更，IDEA/终端构建同样受益。**
- **TRAE 沙箱限制（已解决）**：沙箱曾拦截写 `D:\Dev\Cache\Maven` 导致 `mvn compile` 必挂。**2026-09-26 用户已在设置→权限与审批→自定义配置中添加白名单**，当晚用正式仓库编译成功验证白名单生效。期间创建的 `d:\Dev\WorkSpace\.mvn-tmp-repo`、`.mvn-tmp-settings.xml` 为临时绕过产物，**待删**（或 gitignore）。
- `mvn -Dmaven.repo.local=...` 经 PowerShell→mvn.cmd 传参会失效（实测），临时仓库必须用 `-s settings.xml` 方式指定。
- **MyBatis-Plus 依赖名坑**：Boot 3 专用 starter 官方名是 `mybatis-plus-spring-boot3-starter`（带 spring，3.5.4+ 起提供），不是 `mybatis-plus-boot3-starter`。写错名字的症状是所有镜像 404，极易误判为镜像缺货——先核对 artifactId 再怀疑仓库。
- MySQL root 密码与 Redis 密码统一为 `12345678`（Docker 部署，见 docker-compose.yml）。
- **MySQL 8 认证坑**：连接串必须带 `allowPublicKeyRetrieval=true`（useSSL=false 时 caching_sha2_password 需向服务器取 RSA 公钥），否则 `Public Key Retrieval is not allowed`。
- **StringRedisTemplate 只收字符串**：Hash 写入时 Long 必须先 `String.valueOf`，`BeanUtil.beanToMap` 直接 putAll 会 ClassCastException。
- **nginx 相对路径基于启动时的工作目录**（不是 exe 所在目录）：必须先 cd 进 nginx 目录再启动，否则找不到 conf。
- **端口避让**：本机 3306/6379 已被 med-qa 容器占用，savor 容器映射 3307/6380。
- 待处理小尾巴：`frontend/nginx-1.18.0/logs/error.log` 内含 2022 年原版运行日志（hmdp/lesson 路径字样），属可再生产物——推 GitHub 前 gitignore `logs/`、`temp/`。
